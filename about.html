ABOUT THE ARCADE

THE PROJECT

Bento Arcade is a self-contained collection of classic browser-based mini-games. Built entirely with vanilla HTML, CSS, and JavaScript, it focuses on delivering a retro arcade experience directly in the browser through custom canvas rendering and manual game loops.

DEVELOPMENT

Developed as a technical showcase to demonstrate strict foundational web development. Every mechanic, from collision detection to keyboard state handling, was engineered from scratch without relying on external game engines or automated code generation.
